# Development Guidelines

Before making any code changes, always read and follow:
`.agents/skills/karpathy-guidelines/SKILL.md`

These guidelines are mandatory for all coding tasks in this repository.

Before coding:
1. Understand the problem and inspect the relevant code.
2. Make the smallest correct change.
3. Avoid unnecessary abstractions or refactoring.
4. Do not modify unrelated files.
5. Verify the change with appropriate tests/checks.
6. Review the final diff before completing the task.
